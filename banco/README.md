# 9Pilla Banco (app educativo)

App web instalável do banco educativo 9Pilla, em modo demonstração.

- Abre direto na conta da Raquel com saldo de R$ 1,00.
- Pix, caixinha (100% do CDI), dividendos, renda fixa, metas, perfil e radar de opções.
- Na Vercel, a pasta `api/` busca dados ao vivo (BRAPI, Yahoo Finance e Banco Central).
- No GitHub Pages, o app usa a última leitura salva dentro do `index.html`.

Publicar na Vercel: importar o repositório e escolher `banco` como Root Directory, sem framework e sem comando de build.

Conteúdo educacional, não é recomendação de investimento (Resolução CVM 20). A 9Pilla ainda não é instituição autorizada pelo Banco Central do Brasil.
